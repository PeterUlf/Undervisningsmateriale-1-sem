## 🎮 Øv genvejstaster online

Her er nogle gode ressourcer til at træne genvejstaster:

### VS Code Shortcuts Practice

- **[VSCode.dev](https://vscode.dev/)** - Prøv VS Code direkte i browseren og øv dine genvejstaster uden installation
- **[Shortcut Foo](https://www.shortcutfoo.com/)** - Interaktiv træning af genvejstaster for forskellige editorer og programmer
- **[KeyCombiner](https://keycombiner.com/)** - Lær og træn genvejstaster med interaktive øvelser

### Typing & Keyboard Games

- **[Monkeytype](https://monkeytype.com/)** - Moderne typing-test med fokus på hastighed og præcision
- **[Keybr.com](https://www.keybr.com/)** - Lær blind skrivning og forbedre din tastatur-teknik
- **[TypeRacer](https://play.typeracer.com/)** - Konkurrér mod andre i typing-løb

### Generelle Tips til at lære genvejstaster

1. **Lær én ad gangen** - Fokuser på at mestre 2-3 genvejstaster ad gangen
2. **Brug dem aktivt** - Tving dig selv til at bruge dem i stedet for musen
3. **Print cheat sheet** - Hav en liste ved siden af dig mens du koder
4. **Gentag dagligt** - 10 minutter om dagen gør en stor forskel
5. **Tilpas til dit workflow** - Lær først de genvejstaster du bruger mest

:::tip[Pro Tip]
I VS Code kan du trykke **⌘ + K + ⌘ + S** for at åbne keyboard shortcuts editoren, hvor du kan se og tilpasse alle genvejstaster!
:::
