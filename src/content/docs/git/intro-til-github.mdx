## Vi skal uploade vores første website

<div class="github-intro-overview">
  <div>
    <p>Vi bruger GitHub som vores "host".</p>

    <p>GitHub er en online platform, hvor du kan gemme, dele og samarbejde om kodeprojekter. Den hjælper med versionsstyring og gør gruppeprojekter nemmere og mere organiserede.</p>

    <p>Det er her, vi skal uploade mange af vores projekter i løbet af studiet.</p>

    <p>Vi lærer meget mere om GitHub, og hvad det kan bruges til, senere på studiet.</p>
  </div>

  <img class="github-intro-logo" src="/illustrationer/github-intro/slide-02-github.png" alt="GitHub-logo" />
</div>

## 3. Opret repository på GitHub

<div class="github-intro-two-column">
  <ol>
    <li>Gå til <a href="https://github.com">github.com</a>.</li>
    <li>Opret en konto med din KEA-mail.</li>
    <li>Opret et repository.</li>
    <li>Kald det eventuelt det samme som opgaven, for eksempel "Link til eget site".</li>
  </ol>

## 4. Upload filerne

<div class="github-intro-two-column">
  <ol>
    <li>Tryk på "Upload existing file".</li>
    <li>Vælg filerne <code>index.html</code> og <code>selvportrait.jpg</code>.</li>
    <li>Upload dem.</li>
    <li>Tryk på "Commit changes".</li>
    <li>Gå til "Settings" og derefter "Pages".</li>
  </ol>

  <div class="github-intro-upload-visual">
    <figure class="github-intro-annotated-image github-intro-upload-link">
      <img src="/illustrationer/github-intro/slide-06-upload-existing-file.png" alt="GitHub-linket Uploading an existing file" />

## 5. Slå GitHub Pages til

<div class="github-intro-pages-layout">
  <ol>
    <li>Vælg branch "main".</li>
    <li>Tryk på "Save".</li>
    <li>Vent et øjeblik.</li>
    <li>Tryk derefter på "Visit site".</li>
  </ol>
