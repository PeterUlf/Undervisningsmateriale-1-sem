## Filtrering på siden

Her henter Astro alle bands og renderer listen som HTML.

Hvert band får en `data-day` attribut, så JavaScript bagefter kan skjule eller vise de HTML-elementer, der allerede ligger på siden.

Eksemplet her matcher siden i `hostmon` og bruger tabellen `kunstnere`
med felterne `navn`, `spilledag` og `spilletidspunkt`:

Komponenten kan fx se sådan her ud:

```astro
---
// BandCard.astro
const { band } = Astro.props;
---

<article
  data-band // Markerer elementet som et band-kort
  data-day={band.spilledag} // Gemmer spilledag til filtrering (læses i JS som dataset.day)
>
  <h2>{band.navn}</h2>
  <p>{band.spilledag} kl. {band.spilletidspunkt}</p>
</article>
```

Selve siden kan så bruge komponenten sådan her:

```astro
---
//@ts-nocheck
import BandCard from "../components/BandCard.astro"; // Importerer komponenten med band-kortet

const url = `${import.meta.env.SUPABASE_URL}/rest/v1/kunstnere?select=*`; // URL til Supabase API med kunstnere tabellen
const apiKey = import.meta.env.SUPABASE_PUBLISHABLE_KEY; // API nøgle til autentificering

const bands = await fetch(url, { // Henter alle bands fra databasen
  headers: {
    apikey: apiKey, // Sender API nøgle med i headeren
  },
}).then((res) => res.json()); // Konverterer response til JSON
---

      </nav>

      <h1>Filtrering</h1>
      <p>Her kan du kun filtrere bands efter spilledag.</p>

      <div id="filter-controls"> <!-- Kontrolpanel til filtrering -->
        <button type="button" data-filter-day="all">Alle bands</button> <!-- Vis alle bands -->
        <button type="button" data-filter-day="fredag">Fredag</button> <!-- Filtrer kun fredagens bands -->
        <button type="button" data-filter-day="lørdag">Lørdag</button> <!-- Filtrer kun lørdagens bands -->
      </div>

      <section id="band-list" aria-live="polite"> <!-- Liste over alle bands med tilgængelighed -->
        {bands.map((band) => ( // Løber igennem alle bands og renderer et kort via komponenten
          <BandCard band={band} />
        ))}
      </section>
    </main>

<script>
  //@ts-nocheck
  const filterButtons = document.querySelectorAll("[data-filter-day]"); // Finder alle filter knapper
  const cards = document.querySelectorAll("[data-band]"); // Finder alle band kort

  filterButtons.forEach((button) => { // Tilføjer click event til hver filter knap
    button.addEventListener("click", () => {
      const selectedDay = button.dataset.filterDay; // Henter værdien fra data-filter-day attributten fra den knap brugeren klikkede på

      cards.forEach((card) => { // Løber igennem alle kort et af gangen
        const shouldShow = // shouldShow bliver enten sand eller falsk ud fra betingelserne nedenunder

          // Næste linje tjekker to betingelser med OR (||):
          // Første betingelse (selectedDay === "all") er sand hvis brugeren har valgt "Alle bands" knappen.
          // Anden betingelse (card.dataset.day === selectedDay) sammenligner kortets spilledag med den valgte dag.
          // Hvis mindst én af de to betingelser er opfyldt, bliver shouldShow sat til true, og kortet vil blive vist.
          selectedDay === "all" || card.dataset.day === selectedDay;

        console.log("Skal vises?", shouldShow); // Debug: viser om kortet skal vises
        if (shouldShow) {
          card.classList.remove("hidden"); // Viser kortet hvis shouldShow er TRUE
        } else {
          card.classList.add("hidden"); // Ellers skjules kortet hvis shouldShow ikke er true
        }
      });
    });
  });
</script>

```

Pointen:

- Astro henter data fra `kunstnere` og laver HTML-listen først
- `data-day` ligger på `<article>` inde i komponenten, så JavaScript kan læse dagen senere
- knapperne har `data-filter-day`, så de fortæller hvilket filter der er valgt
- JavaScript tilføjer eller fjerner klassen `.hidden` i stedet for at hente data igen
- CSS-klassen `.hidden { display: none; }` er det, der faktisk skjuler kortene

## Filtrering: hvad sker der?

Først finder vi filterknapperne og band-kortene:

```js
const filterButtons = document.querySelectorAll("[data-filter-day]");
const cards = document.querySelectorAll("[data-band]");
```

Når brugeren klikker, læser vi knappens værdi:

```js
const selectedDay = button.dataset.filterDay;
```

Så går vi igennem alle band-kort og undersøger,
om kortet skal vises eller skjules:

```js
cards.forEach((card) => {
  const shouldShow =
    selectedDay === "all" || card.dataset.day === selectedDay;

  if (shouldShow) {
    card.classList.remove("hidden");
  } else {
    card.classList.add("hidden");
  }
});
```

Det betyder:

- hvis brugeren vælger `Alle bands`, bliver alle kort vist
- hvis brugeren vælger `fredag`, vises kun kort med `data-day="fredag"`
- `classList.remove("hidden")` viser kortet
- `classList.add("hidden")` skjuler kortet

:::tip[Husk at værdierne skal passe sammen]
Hvis jeres data indeholder `Fredag`, men knappen hedder `fredag`,
så matcher filteret ikke.

Værdierne i databasen og i `data-filter-day` skal derfor være skrevet ens.
:::
