## TL;DR

1. Brug `{condition && <element />}` for at vise noget kun når betingelsen er sand
2. Brug `{condition ? <a> : <b>}` for at vælge mellem to muligheder
3. Kombiner betingelser for dynamisk indhold

</Slide>

## Hvad er conditional rendering?

**Conditional rendering** betyder at vise eller skjule indhold baseret på en betingelse.

**Eksempler:**

- Vis en sang kun hvis den er liked
- Vis "Premium" badge hvis kunstneren er verificeret
- Vis play-knap kun hvis sangen er tilgængelig

</Slide>

<div class="page-break"></div>

<Slide>

## && operator – vis kun hvis sand

Brug `&&` til at vise noget kun når en betingelse er opfyldt:

```astro
---
// Song.astro
const { title, artist, isLiked } = Astro.props;
---

<div class="song">
  <h3>{title}</h3>
  <p>{artist}</p>
  {isLiked && <span class="heart">❤️</span>}
</div>
```

**Brug:**

```astro
<Song title="Bohemian Rhapsody" artist="Queen" isLiked={true} />
```

Hvis `isLiked` er `false`, vises hjertet ikke.

</Slide>

<div class="page-break"></div>

<Slide>

## ? : operator – vælg mellem to muligheder

Brug ternary `? :` til at vælge mellem to forskellige ting:

```astro
---
// Account.astro
const { isPremium } = Astro.props;
---

<div class="account">
  {isPremium ? (
    <p>✓ Spotify Premium</p>
  ) : (
    <p>Free Account - <a href="/upgrade">Opgrader</a></p>
  )}
</div>
```

**Brug:**

```astro
<Account isPremium={false} />
```

**Læses som:** "Hvis premium, vis det første, ellers vis det andet"

</Slide>

## Conditional class names

Tilføj CSS classes baseret på betingelser:

```astro
---
// PlayingSong.astro
const { title, artist, isPlaying, isLiked } = Astro.props;
---

<div class={`song ${isPlaying ? 'playing' : ''}`}>
  <h3>{title}</h3>
  <button class={isLiked ? 'liked' : 'not-liked'}>
    {isLiked ? '❤️' : '🤍'}
  </button>
</div>

<style>
  .song.playing {
    background: #1db954;
    color: white;
  }
  .liked {
    color: #1db954;
  }
</style>
```

**Brug:**

```astro
<PlayingSong
  title="Blinding Lights"
  artist="The Weeknd"
  isPlaying={true}
  isLiked={false}
/>
```

## Multiple betingelser

Kombiner flere betingelser:

```astro
---
// Artist.astro
const { name, isVerified, followers } = Astro.props;
---

<div class="artist">
  <h2>
    {name}
    {isVerified && <span class="badge">✓</span>}
  </h2>
  <p>{followers.toLocaleString('da-DK')} følgere</p>
  {followers > 10000000 && (
    <span class="popular">🔥 Mega populær</span>
  )}
</div>
```

**Brug:**

```astro
<Artist
  name="Taylor Swift"
  isVerified={true}
  followers={95000000}
/>
```

## SongCard komponent eksempel

En komplet komponent med conditional rendering:

```astro
---
// SongCard.astro
const {
  title,
  artist,
  coverUrl,
  isLiked = false,
  isPremium = false
} = Astro.props;
---

<div class="song-card">
  {coverUrl && <img src={coverUrl} alt={title} />}

  <div class="info">
    <h3>{title}</h3>
    <p>{artist}</p>
  </div>

  <div class="actions">
    {isLiked && <span>❤️</span>}
    {isPremium && <span class="premium">Premium</span>}
  </div>
</div>

<style>
  .song-card {
    display: flex;
    gap: 1rem;
    padding: 1rem;
    background: #181818;
    border-radius: 8px;
  }
  .premium {
    background: gold;
    color: black;
    padding: 0.25rem 0.5rem;
    border-radius: 4px;
    font-size: 0.75rem;
  }
</style>
```

## Husk

1. **`&&`** – vis kun hvis betingelsen er sand
2. **`? :`** – vælg mellem to muligheder
3. **`.filter()`** – filtrer arrays før du viser dem
4. Hold det simpelt og læsbart

5. **Filtrer data tidligt** – filtrer arrays i frontmatter, ikke i template
6. **Standardværdier** – brug standardværdier på props: `showIcon = true`
7. **Type-sikkerhed** – definer interfaces for props med valgfrie felter
8. **Læsbarhed** – undgå dybt nestede ternary operators

</Slide>
