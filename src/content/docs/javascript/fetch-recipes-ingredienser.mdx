## Hvad lærer du her?

På denne side arbejder du med **recipes data** og lærer:

1. Hvordan du arbejder med et objekt der indeholder et array
2. Hvordan du finder arrayet med opskrifter inde i objektet
3. Hvordan du viser ingredienser fra et array inde i hvert recipe-objekt med `.map()` og `.join()`

## Data-strukturen

<div style="display: grid; grid-template-columns: 1fr 1fr; gap: 2rem; align-items: start;">

Vores recipes data ser sådan ud:

```json
{
  "recipes": [
    {
      "id": 1,
      "name": "Classic Margherita Pizza",
      "ingredients": [
        "Pizza dough",
        "Tomato sauce",
        "Fresh mozzarella cheese",
        "Fresh basil leaves",
        "Olive oil",
        "Salt and pepper to taste"
      ]
    }
  ]
}
```

</div>

<div>

### Sådan skal du læse strukturen:

- `data` er et objekt med en `recipes` key
- `recipes` indeholder et array af opskrifter
- Hver opskrift har `id`, `name` og `ingredients`
- Vi kalder `showRecipes(data.recipes)` for at vise opskrifterne

**Vigtigt:** Vi sender `data.recipes` videre, fordi det er arrayet inde i objektet.

## JavaScript: Komplet kode

```javascript
// Data objekt med opskrifter
const data = {
  recipes: [
    {
      id: 1,
      name: "Classic Margherita Pizza",
      ingredients: [
        "Pizza dough",
        "Tomato sauce",
        "Fresh mozzarella cheese",
        "Fresh basil leaves",
        "Olive oil",
        "Salt and pepper to taste",
      ],
    },
    {
      id: 2,
      name: "Spaghetti Carbonara",
      ingredients: [
        "Spaghetti",
        "Eggs",
        "Parmesan cheese",
        "Pancetta",
        "Black pepper",
      ],
    },
    {
      id: 3,
      name: "Chocolate Chip Cookies",
      ingredients: [
        "Flour",
        "Butter",
        "Sugar",
        "Brown sugar",
        "Eggs",
        "Chocolate chips",
        "Vanilla extract",
        "Baking soda",
      ],
    },
  ],
};

function showRecipes(recipes) {
  // Start med tom variabel
  listContainer = "";

  // recipes er et array af objekter
  recipes.forEach((recipe) => {
    listContainer += `
      <article class="recipeCard">
        <h3>${recipe.name}</h3>
        <h4>Ingredienser:</h4>
        <ul>
          ${recipe.ingredients.map((ingredient) => `<li>${ingredient}</li>`).join("")}
        </ul>
      </article>
    `;
    console.log("Min listcontainer er nu", listContainer);
  });
}

// Kald funktionen med data
showRecipes(data.recipes);
```

## Trin-for-trin forklaring

### 1. Loop gennem hver opskrift

```javascript
recipes.forEach((recipe) => {
  // Gør noget med hver opskrift
});
```

- `forEach()` går gennem hvert element i `recipes` arrayet
- Vi kalder hvert element for `recipe`

</Slide>
<div class="page-break"></div>

<Slide>

## Trin-for-trin forklaring

### 2. Vis ingredienserne med map()

Hele linjen ser sådan ud:

```javascript
${recipe.ingredients.map((ingredient) => `<li>${ingredient}</li>`).join("")}
```

**Lad os dele den op i trin:**

### Trin 1: Hent arrayet

```javascript
recipe.ingredients;
// Resultat: ["Pizza dough", "Tomato sauce", "Fresh mozzarella cheese"]
```

### Trin 2: Brug .map() til at lave HTML

```javascript
.map((ingredient) => `<li>${ingredient}</li>`)
// Resultat: ["<li>Pizza dough</li>", "<li>Tomato sauce</li>", "<li>Fresh mozzarella cheese</li>"]
```

### Trin 3: Brug .join("") til at sætte sammen

```javascript
.join("")
// Resultat: "<li>Pizza dough</li><li>Tomato sauce</li><li>Fresh mozzarella cheese</li>"
```

**Finalresultat:** Én lang HTML-string med alle ingredienser som listeelementer!

## Sammenfatning

**Husk:**

1. Vores recipes data er et **objekt**, ikke et array direkte
2. Du skal bruge `data.recipes` for at få fat i arrayet
3. Ingredienser er et **array inde i hvert objekt**
4. Brug `.map()` til at transformere hvert element
5. Brug `.join("")` til at sætte array-elementer sammen til én string
