## Hvad er .map()?

`.map()` er en array-metode som laver om på **hvert element** i et array og returnerer et **nyt array**.

### Simpelt eksempel:

```javascript
const prices = [10, 25, 50];
const pricesWithKr = prices.map((price) => "kr: " + price);
console.log(pricesWithKr); // ["kr: 10", "kr: 25", "kr: 50"]
```

### Hvordan det virker:

1. `.map()` går gennem hvert element i arrayet
2. For hvert element kører den funktionen `(price) => "kr: " + price`
3. Den gemmer resultatet i et nyt array
4. Det nye array returneres

**Vigtigt:** Det originale array ændres ikke!

## .map() visuelt forklaret

```javascript
const prices = [10, 25, 50];
```

Lad os se hvad der sker i hver gennemgang:

**1. gang:** `price` er `10` → returnerer `"kr: 10"`  
**2. gang:** `price` er `25` → returnerer `"kr: 25"`  
**3. gang:** `price` er `50` → returnerer `"kr: 50"`

**Resultat:** Et nyt array `["kr: 10", "kr: 25", "kr: 50"]`

```javascript
console.log(prices); // [10, 25, 50] - originalen er ikke ændret!
```

## Flere .map() eksempler

### Eksempel 1: Dobbelt værdier

```javascript
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map((num) => num * 2);
console.log(doubled); // [2, 4, 6, 8, 10]
```

### Eksempel 2: Lav navne om til store bogstaver

```javascript
const names = ["anna", "ben", "clara"];
const upperNames = names.map((name) => name.toUpperCase());
console.log(upperNames); // ["ANNA", "BEN", "CLARA"]
```

### Eksempel 3: Lav HTML-tags

```javascript
const items = ["Æbler", "Bananer", "Appelsiner"];
const listItems = items.map((item) => `<li>${item}</li>`);
console.log(listItems); // ["<li>Æbler</li>", "<li>Bananer</li>", "<li>Appelsiner</li>"]
```

## Hvad er .join()?

`.join()` er en array-metode som **sætter alle elementer sammen** til én string.

### Byg videre på forrige eksempel:

```javascript
const prices = [10, 25, 50];
const pricesWithKr = prices.map((price) => "kr: " + price);
// pricesWithKr er nu: ["kr: 10", "kr: 25", "kr: 50"]

const priceString = pricesWithKr.join(" og ");
console.log(priceString); // "kr: 10 og kr: 25 og kr: 50"
```

### Hvordan det virker:

1. `.join()` går gennem alle elementer i arrayet
2. Den sætter dem sammen til én lang string
3. Mellem hvert element indsætter den det du skriver i parentesen
4. Den returnerer den nye string

</Slide>

## .join() med forskellige separatorer

Samme array, forskellige resultater:

```javascript
const pricesWithKr = ["kr: 10", "kr: 25", "kr: 50"];
```

### Komma og mellemrum

```javascript
pricesWithKr.join(", "); // "kr: 10, kr: 25, kr: 50"
```

### Ingen separator

```javascript
pricesWithKr.join(""); // "kr: 10kr: 25kr: 50"
```

### Bindestreg

```javascript
pricesWithKr.join(" - "); // "kr: 10 - kr: 25 - kr: 50"
```

### Linjeskift

```javascript
pricesWithKr.join("\n"); // "kr: 10
// kr: 25
// kr: 50"
```

## .map() og .join() sammen

Disse to metoder bruges ofte sammen i én linje:

```javascript
const fruits = ["æble", "banan", "pære"];

const sentence = fruits.map((fruit) => fruit.toUpperCase()).join(" - ");
console.log(sentence); // "ÆBLE - BANAN - PÆRE"
```

**Hvad sker der?**

1. `.map()` laver om: `["æble", "banan", "pære"]` → `["ÆBLE", "BANAN", "PÆRE"]`
2. `.join(" - ")` sætter sammen: `["ÆBLE", "BANAN", "PÆRE"]` → `"ÆBLE - BANAN - PÆRE"`

## Praktisk eksempel: Lav en liste

Byg en komplet HTML-liste:

```javascript
const ingredients = ["Pizza dough", "Tomato sauce", "Mozzarella"];

const htmlList = ingredients
  .map((ingredient) => `<li>${ingredient}</li>`)
  .join("");

console.log(htmlList);
// "<li>Pizza dough</li><li>Tomato sauce</li><li>Mozzarella</li>"
```

**Brug det i din HTML:**

```javascript
document.querySelector("#list").innerHTML = htmlList;
```

**Resultat i browseren:**

- Pizza dough
- Tomato sauce
- Mozzarella

## Lille øvelse med `map()` i CodePen

**Lav denne øvelse i CodePen:**

1. Opret en tom container i HTML-panelet.
2. Brug `map()` til at lave et nyt array med HTML for hver studerende.
3. Sæt resultatet ind på siden med `join("")` og `innerHTML`.

### HTML

```html
<section id="app"></section>
```

### JavaScript

```javascript
const students = [
  { first_name: "Asta", last_name: "Jensen", class_name: "A" },
  { first_name: "Malik", last_name: "Ali", class_name: "B" },
  { first_name: "Sofie", last_name: "Hansen", class_name: "C" },
];

const app = document.querySelector("#app");

const studentCards = students.map((student) => {
  return `
    <article>
      <h2>...</h2>
      <p>Klasse: ...</p>
    </article>
  `;
});

app.innerHTML = studentCards.join("");
```

### Diskuter med sidemanden

- hvad er students (flertal) er
- hvad er student (ental) er
- hvad er forskellen fra at bruge forEach

### Din opgave

- indsæt studerendes fornavn og efternavn i `<h2>`
- indsæt holdet i `<p>`
- tjek at der kommer 3 `<article>`-kort på siden

:::tip[Hint]
I CodePen bliver resultatet fra `map()` et array med HTML-strenge. Derfor bruger vi `join("")`, før vi sætter det ind med `innerHTML`.
:::

## Sammenfatning

### .map()

- Transformerer hvert element i et array
- Returnerer et **nyt array** med samme længde
- Ændrer ikke det originale array

### .join()

- Sætter alle elementer sammen til **én string**
- Du vælger selv separatoren mellem elementerne
- Standard separator er komma hvis du ikke angiver noget

### Sammen

Perfekte til at bygge HTML fra arrays:

```javascript
array.map((item) => `<tag>${item}</tag>`).join("");
```
