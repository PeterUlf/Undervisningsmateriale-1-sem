## Grundidéen i `filter()`

`filter()` gennemgår et array og returnerer kun de elementer, hvor betingelsen er `true`.

```javascript
const numbers = [3, 8, 12, 15, 22];
const evenNumbers = numbers.filter((num) => num % 2 === 0);

console.log(evenNumbers); // [8, 12, 22]
```

Grundig forklaring af linjen:

`const evenNumbers = numbers.filter((num) => num % 2 === 0);`

1. `numbers.filter(...)` betyder: "Gå alle tal i `numbers` igennem, og behold kun dem hvor betingelsen er `true`."
2. `(num) => ...` er callback-funktionen, der kører én gang pr. tal i arrayet.
3. `num % 2` finder resten, når tallet deles med 2.
4. `=== 0` tjekker om resten er 0.
5. Hvis resultatet er `true`, kommer tallet med i `evenNumbers`.
6. Hvis resultatet er `false`, bliver tallet sorteret fra.

Sådan evalueres eksemplet:

1. `3 % 2 = 1` -> `1 === 0` er `false` -> `3` fjernes.
2. `8 % 2 = 0` -> `0 === 0` er `true` -> `8` beholdes.
3. `12 % 2 = 0` -> `true` -> `12` beholdes.
4. `15 % 2 = 1` -> `false` -> `15` fjernes.
5. `22 % 2 = 0` -> `true` -> `22` beholdes.

Resultatet bliver derfor `[8, 12, 22]`.

Vigtigt:

1. `filter()` laver et nyt array.
2. Original-arrayet `numbers` ændres ikke.

const onlyInStock = products.filter((product) => product.soldout === 0);

## Brug filtrering i dit projekt

Et simpelt setup:

1. Gem alle produkter i `allProducts`
2. Hold styr på valgt filter (fx `selectedCategory`)
3. Filtrer data, og kald `showProducts(filtered)`

```javascript
const allProducts = []; // fyldes efter fetch
let selectedCategory = "all";

function applyFilter() {
  const filteredProducts = allProducts.filter((product) => {
    if (selectedCategory === "all") return true;
    return product.category === selectedCategory;
  });

  showProducts(filteredProducts);
}
```

## Eksempel: Filtreringsknap + filtreringsfunktion

Hvis I allerede har en fetch-løsning, kan I tilføje en filtreringsknap,
som kalder en filtreringsfunktion og viser et udvalgt udsnit af produkterne.

HTML:

```html
<button id="filterWomenBtn">Vis kun Women</button>
<button id="showAllBtn">Vis alle</button>
<section id="productListContainer"></section>
```

JavaScript:

```javascript
const listURL = "https://kea-alt-del.dk/t7/api/products";
const listContainer = document.querySelector("#productListContainer");
const filterWomenBtn = document.querySelector("#filterWomenBtn");
const showAllBtn = document.querySelector("#showAllBtn");

let allProducts = [];

function getProducts() {
  fetch(listURL)
    .then((res) => res.json())
    .then((products) => {
      allProducts = products; // gem originaldata
      showProducts(allProducts);
    });
}

function showProducts(products) {
  listContainer.innerHTML = "";

  products.forEach((product) => {
    listContainer.innerHTML += `
      <article class="productCard">
        <h3>${product.productdisplayname}</h3>
        <p>Gender: ${product.gender}</p>
        <p>Pris: ${product.price}</p>
      </article>
    `;
  });
}

function filterByGender(targetGender) {
  const filtered = allProducts.filter(
    (product) =>
      (product.gender || "").toLowerCase() === targetGender.toLowerCase()
  );

  showProducts(filtered);
}

filterWomenBtn.addEventListener("click", () => filterByGender("Women"));
showAllBtn.addEventListener("click", () => showProducts(allProducts));

getProducts();
```

Sådan forklarer du det til studerende:

1. Vi gemmer alle produkter i `allProducts`.
2. Filtreringsknappen kalder filtreringsfunktionen.
3. Filtreringsfunktionen bruger `filter()` og returnerer kun de produkter, der matcher kriteriet.
4. Resultatet renderes med `showProducts(...)`.
