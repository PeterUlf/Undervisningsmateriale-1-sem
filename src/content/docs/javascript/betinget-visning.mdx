## Grundstruktur: `${condition ? "A" : "B"}`

```javascript
`${condition ? "A" : "B"}`;
```

Forklaring:

1. `${...}` betyder: indsæt JavaScript inde i en template literal.
2. `condition ? "A" : "B"` er en ternary (kort if/else).
3. Hvis `condition` er sand, indsættes `"A"`.
4. `: "B"` betyder: hvis betingelsen er falsk, indsættes B.
5. `: ""` bruges, når class eller HTML kun skal være der i nogle tilfælde.

Eksempel med class:

```javascript
`<article class="smallProduct ${product.discount > 0 ? "onSale" : ""}">`;
```

Her bruges ternary direkte i en class:

hvis product.discount > 0 er sand, bliver class onSale tilføjet
ellers indsættes tom streng "" (ingen ekstra class)
den class kan du bruge i CSS til styling, fx farve, badge eller kant på tilbudsvarer

Eksempel med HTML:

```javascript
`${product.discount > 0 ? "<p>Tilbud</p>" : ""}`;
```

## Ternary inde i template literal

```javascript
`<article class="smallProduct ${product.discount > 0 ? "onSale" : ""}">`;
```

Her bruges ternary direkte i en class:

1. samme idé bruges til at vise/skjule rabatboksen, så den kun vises når den er relevant (`discount > 0`)

Samme mønster kan bruges til at udregne prisen:

```javascript
`${
  product.discount > 0
    ? `<p>Now DKK <span>${(product.price * (1 - product.discount / 100)).toFixed(2)}</span>,-</p>
       <p><span>${product.discount}</span>%</p>`
    : ""
}`;
```

## Typiske fejl

1. Du skriver `categori` i stedet for `category` i variabelnavne/logs.
2. Du glemmer `productList.innerHTML = ""`, så listen bliver duplikeret.
3. Du bruger ternary uden `: ""`, så du får `undefined` i markup.
4. Du logger en variabel, der ikke findes, fx `console.log(markup)`.
5. Du glemmer `Number(product.discount)`, hvis værdien kommer som tekst.
