## Hvad lærer du her?

Du lærer de tre mest brugte måder at lave betinget visning i JavaScript:

1. `\${condition ? "A" : "B"}`
2. `\${condition && "A"}`
3. `\${condition || "A"}`

Strukturen på siden:

1. Forklaring af hvert koncept
2. CodePen-opgaver uden API
3. CodePen-opgaver med dit produktmateriale

Tip: Brug template literals (backticks), når du indsætter betinget markup.

## 1) Ternary `?:` (if/else i en linje)

Grundstruktur:

```javascript
`${condition ? "A" : "B"}`;
```

Hvornår bruger du den?

1. Når du har et klart valg mellem to outputs.
2. Når der altid skal komme noget tilbage (fx tekst A eller tekst B).
3. Når du vil undgå en længere `if/else` inde i markup.

Eksempel:

```javascript
const age = 17;
const adgang = `${age >= 18 ? "Voksen" : "Under 18"}`;
```

I templates bruges den ofte sådan her:

```javascript
`<p>${isLoggedIn ? "Velkommen tilbage" : "Log ind"}</p>`;
```

Vigtigt: Ved skjul/visning bruger man tit `: ""` på den falske gren.

## Opgaver: Ternary (med dit materiale)

Brug et produkt-objekt (enten hardcoded eller fra API):

```javascript
const product = {
  productdisplayname: "Trail Shoes",
  price: 799,
  discount: 20,
  soldout: 0,
  brandname: "",
};
```

Løs disse:

1. Vis class `onSale` hvis `product.discount > 0`, ellers tom streng.
2. Vis `<p class="badge">Tilbud</p>` hvis `discount > 0`, ellers ingenting.
3. Vis `"Udsolgt"` hvis `soldout === 1`, ellers `"På lager"`.
4. Vis brandnavn hvis `brandname` findes, ellers teksten `"Ukendt brand"`.

Skriftlige hints (uden facit):

1. Start med at lave 4 små hjælpe-variabler før `innerHTML`:
   `saleClass`, `badgeHtml`, `stockText`, `brandText`.
2. Brug ternary i hver variabel, så du kun løser én betingelse ad gangen.
3. `#card_wrapper` er kun en container.
   Du skal selv oprette card-elementet inde i `card_wrapper.innerHTML`.
4. Brug `saleClass` inde i class-attributten på dit card:
   ``<article class="card ${...}">``.
5. Brug `badgeHtml` som en separat linje i templaten (så den kan være tom eller indeholde `<p class="badge">...</p>`).
6. `brandname` er en tom streng i startdata, så fallback-teksten skal vises i første test.

```javascript
// Byg selv markup med ternary i card_wrapper.innerHTML
// #card_wrapper er kun container - opret selv <article class="card ..."> i templaten
// Hint 1: lav først hjælpevariabler (saleClass, badgeHtml, stockText, brandText)
// Hint 2: brug bagefter variablerne inde i templaten
// Hint 3: brug både class-attribut + tekst/HTML med ternary

  <article class="card ...">

  </article>
`;
```

## Løsningsforslag: Ternary (med dit materiale)

Her er én mulig løsning på opgaven ovenfor.

<div class="columns-2">

<div>
HTML-boks:

```html
<main class="exercise-wrap">
  <section id="card_wrapper"></section>
</main>
```

</div>
<div>
JavaScript-boks (løsning):

```javascript
const card_wrapper = document.querySelector("#card_wrapper");
const product = {
  productdisplayname: "Trail Shoes",
  price: 799,
  discount: 20,
  soldout: 0,
  brandname: "",
};

const saleClass = product.discount > 0 ? "onSale" : "";
const badgeHtml = product.discount > 0 ? `<p class="badge">Tilbud</p>` : "";
const stockText = product.soldout === 1 ? "Udsolgt" : "På lager";
const brandText = product.brandname ? product.brandname : "Ukendt brand";
const priceText =
  product.discount > 0
    ? (product.price * (1 - product.discount / 100)).toFixed(2)
    : product.price;

card_wrapper.innerHTML = `
  <article class="card ${saleClass}">
    ${badgeHtml}
    <h3>${product.productdisplayname}</h3>
    <p>Status: ${stockText}</p>
    <p>Brand: ${brandText}</p>
    <p>Pris: ${priceText} kr.</p>
  </article>
`;
```

</div>

</div>

Tjekliste:

1. `saleClass` giver `onSale` kun ved rabat.
2. `badgeHtml` er tom streng når der ikke er rabat.
3. `stockText` viser korrekt status fra `soldout`.
4. `brandText` falder tilbage til `"Ukendt brand"`.

## 2) `&&` (vis kun noget når betingelsen er sand)

Grundstruktur:

```javascript
`${condition && "A"}`;
```

Hvornår bruger du den?

1. Når noget kun skal vises i true-tilfældet.
2. Når du ikke har brug for en `else`-gren.
3. Til badges, labels og ekstra HTML-blokke.

Eksempel:

```javascript
`<p>${isAdmin && "Admin-panel"}</p>`;
```

Hvis `isAdmin` er false, får du ikke et alternativ som i ternary.

</Slide>

1. Lav `hasNotification = true` og vis `<span>Ny besked</span>` kun når den er true.

3. Lav `showHelp = true` og vis en `<section>` med hjælpetekst kun i true-tilfældet.
4. Lav en class-string der kun tilføjer `"highlight"` når `isSelected` er true.

## 3) `||` (fallback/default-værdi)

Grundstruktur:

```javascript
`${condition || "A"}`;
```

Hvornår bruger du den?

1. Når du vil have en reserveværdi.
2. Når en variabel kan være tom, `null` eller `undefined`.
3. Når noget altid skal vises, også hvis data mangler.

Eksempel:

```javascript
const nickname = "";
`<p>${nickname || "Anonym bruger"}</p>`;
```

Hvis venstre side er falsy, bruges højre side.

## Hurtig huskeregel

1. `?:` når du skal vælge mellem to tydelige outputs.
2. `&&` når noget kun skal vises i true-tilfældet.
3. `||` når du vil have en fallback/default-værdi.

Typisk kombination i samme template:

```javascript
`
  <article class="smallProduct ${product.discount > 0 ? "onSale" : ""}">
    ${product.discount > 0 && `<p class="badge">${product.discount}%</p>`}
    <p>${product.brandname || "Ukendt brand"}</p>
  </article>
`;
```

Hvis du er i tvivl: start med ternary. Skift til `&&` kun når du ikke har en else.
