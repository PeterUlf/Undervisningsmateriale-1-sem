## Hvad er et Array?

Et **array** er en liste af værdier. I stedet for at have én værdi i en variabel, kan du have mange værdier i et array.

```javascript
// Én værdi
const product = "Laptop";

// Mange værdier i et array
const products = ["Laptop", "Mouse", "Keyboard", "Monitor"];
```

Arrays er perfekte til at gemme og arbejde med lister af data:

- Produkter
- Brugere
- Billeder
- Menupunkter
- osv.

## Opret et Array

Du opretter arrays med firkantede parenteser `[]`:

```javascript
// Tomt array
const emptyArray = [];

// Array med strenge
const fruits = ["Æble", "Banan", "Appelsin"];

// Array med tal
const numbers = [1, 2, 3, 4, 5];

// Array med blandede typer
const mixed = ["Tekst", 42, true, null];

// Array med objekter
const products = [
  { name: "Laptop", price: 8999 },
  { name: "Mouse", price: 299 },
  { name: "Keyboard", price: 599 },
];
```

## Tilgå elementer i et Array

Arrays bruger **index** til at tilgå elementer. Index starter ved **0** (ikke 1!).

```javascript
const fruits = ["Æble", "Banan", "Appelsin", "Pære"];

// Tilgå elementer
console.log(fruits[0]); // "Æble" (første element)
console.log(fruits[1]); // "Banan" (andet element)
console.log(fruits[2]); // "Appelsin" (tredje element)
console.log(fruits[3]); // "Pære" (fjerde element)

// Index der ikke findes
console.log(fruits[4]); // undefined

// Sidste element
console.log(fruits[fruits.length - 1]); // "Pære"
```

:::tip[Husk!]
Arrays starter ved index 0, så første element er `array[0]`, ikke `array[1]`.
:::

## Array Length

Brug `.length` til at finde antal elementer:

```javascript
const fruits = ["Æble", "Banan", "Appelsin"];

console.log(fruits.length); // 3

// Check om array er tomt
if (fruits.length === 0) {
  console.log("Array er tomt!");
}

// Sidste element
const lastFruit = fruits[fruits.length - 1];
console.log(lastFruit); // "Appelsin"
```

## Loop gennem et Array

### forEach() - Moderne måde

```javascript
const fruits = ["Æble", "Banan", "Appelsin"];

fruits.forEach((fruit) => {
  console.log(fruit);
});

// Med index
fruits.forEach((fruit, index) => {
  console.log(`${index}: ${fruit}`);
});
// 0: Æble
// 1: Banan
// 2: Appelsin
```
