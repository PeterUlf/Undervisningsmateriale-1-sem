## Popover eller modal dialog?

| Popover                           | Modal dialog                                                |
| --------------------------------- | ----------------------------------------------------------- |
| Ekstra indhold over siden.        | En opgave eller beslutning får fokus.                       |
| Resten af siden bliver ikke låst. | Resten af siden bliver utilgængelig, mens dialogen er åben. |
| Fx information om materialer.     | Fx bekræftelse før en sletning.                             |
| `popover` på et HTML-element.     | `<dialog>` åbnet modalt, fx med `showModal()`.              |

Et mørkt baggrundslag gør ikke i sig selv en popup modal. Et `<dialog>`-element kan også åbnes uden at være modalt.

Vi bruger popover til supplerende indhold, som brugeren selv kan åbne.

</Slide>

## En knap og et matchende id

```html
<button type="button" popovertarget="materialer">Se materialer</button>

<div id="materialer" popover>
  <h2>Det ligger klar til dig</h2>
  <p>Vi har papir, farver og pensler.</p>
</div>
```

- `popover` giver boksen browserens åbne/lukke-funktion.
- `id` identificerer boksen. Hvert id skal være unikt.
- `popovertarget` skal matche id’et præcist, uden `#`.

Find de to steder, hvor der står `materialer`. De danner forbindelsen.

## Åbn og luk

Når du bruger en popover, fungerer knappen automatisk som en tænd/sluk-kontakt: Et klik åbner popoveren, og det næste klik lukker den igen. Klik udenfor eller <kbd>Esc</kbd> lukker også boksen.

```html
<!-- Denne knap står inde i boksen -->
<button type="button" popovertarget="materialer" popovertargetaction="hide">
  Luk
</button>
```

`popovertargetaction` kan være `show`, `hide` eller `toggle`. Uden attributten er handlingen `toggle`.

`popover="manual"` kræver en eksplicit lukkehandling. Klik udenfor og Esc lukker den ikke automatisk. Vi bruger `auto` i øvelserne.

En tydelig “Luk”-knap hjælper brugeren med at finde udgangen.

## CSS til boksen og dens tilstand

```css
[popover] {
  border: 2px solid #185a46;
}

[popover]:popover-open {
  display: grid;
  gap: 0.75rem;
}

[popover]::backdrop {
  background: rgb(24 53 46 / 18%);
}
```

`[popover]` er en attribut-selector. `:popover-open` vælger den åbne tilstand. `::backdrop` er laget bag boksen.

Sæt kun `display: grid` på den åbne tilstand. Ellers kan du tilsidesætte browserens skjulning med `display: none`.

## Virker det for en anden?

**Makkerafprøvning · 4 minutter**

| Niveau              | Det skal I kunne vise                                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| På vej              | En boks åbner. Et forkert target, en lukkeknap eller størrelsen mangler stadig at blive rettet.                             |
| Det fungerer        | Begge knapper viser den rigtige boks. “Luk”, klik udenfor og Esc virker. Den lange tekst kan læses i et smalt resultatfelt. |
| Du kan forklare det | I viser det med Tab og Enter og forklarer id/target, den åbne selector og valget af maksimal højde.                         |

Byt betjening. Find én konkret ting at forbedre, ret den, og afprøv igen.

Tastatur: Tab til knappen, Enter for at åbne, videre til “Luk”, eller brug Esc.

## Hvad vil I bruge den til?

**Tilbage til jeres projekt · 3 minutter**

Tag idéen fra summeøvelsen frem igen. Ville I stadig vælge en popup?

- Hvilken knap åbner den, og hvad får brugeren at vide?
- Kan brugeren have brug for informationen direkte på siden?
- Hvordan kan brugeren lukke og fortsætte?

Del én begrundet beslutning. En placering direkte på siden kan også være et godt valg.
