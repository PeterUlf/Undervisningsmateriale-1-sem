## Flyt din figur med et klik

En besøgende klikker på **Scene**. Teksten foldes ud, og en figur i illustrationen flytter hen til scenen.

Du bygger forbindelsen i tre trin:

1. Få et klik på `<summary>` til at køre en funktion.
2. Flyt den del af SVG’en, du viser med `<use>`.
3. Lad forskellige valg flytte figuren til forskellige steder.

<div class="slide-takeaway">

**Grundforløb: ca. 35 minutter · små individuelle trin i CodePen.** Du bruger `querySelector`, `addEventListener`, funktioner og `.style` fra JavaScript-undervisningen. Til sidst kan du bruge samme fremgangsmåde med din egen figur.

**Udvidelse efter slide 12: ca. 20 minutter.** Brug en SVG-fil, og lad figurens position og størrelse følge det åbne afsnit.

</div>

</Slide>

## Start med det, brugeren klikker på

```html
<details>
  <summary id="vaelg-scene">Scene</summary>
  <p>Her kan du høre musikken.</p>
</details>

<p id="besked">Vælg et sted.</p>
```

- `<details>` indeholder det afsnit, der kan åbnes og lukkes.
- `<summary>` er den synlige overskrift, brugeren aktiverer.
- `id="vaelg-scene"` gør det let at finde netop denne overskrift i JavaScript.

**HTML klarer allerede åbning og lukning.** Nu skal det samme klik også ændre beskeden under afsnittet.

<div class="slide-takeaway">

`summary` ligger inde i `details`. Selectoren `details summary` finder en sådan overskrift; `#vaelg-scene` finder vores konkrete valg. Der skal ikke stå `details:summary`.

</div>

## Lad klikket køre en funktion

```javascript
document.querySelector("#vaelg-scene").addEventListener("click", vaelgScene);

function vaelgScene() {
  document.querySelector("#besked").textContent = "Du valgte scenen.";
}
```

1. `querySelector()` finder overskriften med det rigtige id.
2. `addEventListener("click", vaelgScene)` lytter efter klik og kalder funktionen.
3. Funktionen finder **et andet element** og ændrer dets tekst.

Skriv `vaelgScene` **uden `()` i listeneren**. Funktionen skal først køre ved klik. `vaelgScene()` ville kalde den med det samme.

**I egne filer:** Placér `<script src="./js/script.js"></script>` lige før `</body>`, så elementerne findes, når scriptet kører. I CodePen skriver du kun JavaScript-koden i JS-panelet.

**4 minutter · individuelt.** Klik på Scene i eksemplet. Åbn derefter CodePen, og giv **Indgang** en listener og en funktion, som ændrer beskeden til `Du valgte indgangen.`

## Flyt figurens use-element

Din SVG kan bestå af en baggrund og en figur. Giv delene hver sit id i SVG-filen, og vis dem med hver sit `<use>` i HTML:

```html
<svg viewBox="0 0 600 300">
  <use href="./svg/kort.svg#baggrund"></use>
  <use class="figur" href="./svg/kort.svg#person"></use>
</svg>
```

| Del af koden     | Det betyder den                                                 |
| ---------------- | --------------------------------------------------------------- |
| `./svg/kort.svg` | Filen med tegningen. Brug din egen filsti og dens `viewBox`.    |
| `#person`        | Den gruppe i filen, som har `id="person"`.                      |
| `class="figur"`  | Vores navn på det `<use>`, vi vil flytte med CSS og JavaScript. |

**Styr `.figur` på siden.** Så flytter du hele den genbrugte figur samlet. Baggrundens `<use>` bliver stående.

Figuren skal være adskilt fra baggrundsgruppen, så den ikke også vises som en fast del af baggrunden. Brug Live Server og en SVG-fil på samme website.

</Slide>

## Flyt figuren med translate

<div class="slide-split">
<div>

```css
.figur {
  transform-box: view-box;
  translate: 40% 0%;
}
```

`translate` forskyder figuren fra dens oprindelige placering. Første værdi er **vandret**, anden er **lodret**.

</div>
<div>

| Værdi      | Flytning             |
| ---------- | -------------------- |
| `0% 0%`    | Oprindelig placering |
| `40% 0%`   | Mod højre            |
| `0% 40%`   | Nedad                |
| `40% -10%` | Mod højre og opad    |

</div>
</div>

`transform-box: view-box` får procentværdierne til at bruge SVG’ens `viewBox`: vandret i forhold til bredden, lodret i forhold til højden.

I en `viewBox="0 0 600 300"` er **40 % vandret = 240 enheder** og **40 % lodret = 120 enheder**. Flytningen skalerer sammen med tegningen.

<div class="slide-takeaway">

Værdierne er en **forskydning fra figurens udgangspunkt**. `40% 0%` flytter ikke figuren 40 % længere for hvert klik.

</div>

</Slide>

## Skift position inde i funktionen

Nu skal klikket gøre det, du lige gjorde manuelt i CSS:

```javascript
document.querySelector("#vaelg-scene").addEventListener("click", gaaTilScene);

function gaaTilScene() {
  document.querySelector(".figur").style.translate = "40% 0%";
}
```

- `#vaelg-scene` er den `summary`, brugeren klikker på.
- `.figur` finder det `<use>`, der skal flyttes.
- `.style.translate` sætter CSS-egenskaben `translate` på elementet. Begge værdier står i **samme tekststreng**.

Behold `transform-box: view-box` i CSS. JavaScript ændrer kun forskydningen.

<div class="slide-takeaway">

**Klik → funktion → ny forskydning.** Klikker du på Scene igen for at lukke teksten, kører funktionen igen. Figuren bliver ved scenen. Den følger det seneste klik.

</div>

## Få figuren til at gå til Café

**5 minutter · individuelt · fortsæt i CodePen 3.** Café ligger på en anden række. Forbind valget med den rigtige forskydning i begge retninger.

1. Find Cafés `summary` i HTML, og brug dens id i en ny `click`-listener.
2. Opret funktionen `gaaTilCafe`, og sæt figurens `translate`.
3. Lad funktionen også ændre `#besked` til `Figuren står ved caféen.`
4. Afprøv **Café → Scene → Indgang → Café → luk Café**.

**Det virker, når:** Figuren rammer alle tre steder, beskeden passer, og kun teksten lukker ved sidste klik. Prøv også rækkefølgen med Tab og Enter og i et smalt resultatvindue.

<details>
<summary>Hint</summary>

Brug `#vaelg-cafe` til klikket og `.figur` til flytningen. Du fandt Café-positionen i CodePen 2. De to procenttal regnes stadig fra Indgang, uanset hvor figuren står nu.

</details>

<details>
<summary>Et løsningsforslag</summary>

Tilføj koden i JS-panelet, og behold de to eksisterende forbindelser:

```javascript
document.querySelector("#vaelg-cafe").addEventListener("click", gaaTilCafe);

function gaaTilCafe() {
  document.querySelector(".figur").style.translate = "40% 40%";
  document.querySelector("#besked").textContent = "Figuren står ved caféen.";
}
```

Den første værdi flytter personen 240 enheder til højre; den anden flytter personen 120 enheder ned. Ved gentagne klik bliver personen samme sted.

</details>

<div class="slide-takeaway">

**Videre, når det virker:** Forklar, hvilket element der modtager klikket, og hvilket der flyttes. Hvis kun teksten åbner, så kontrollér listenerens selector og funktionsnavn først.

## Lad figuren glide til sin plads

Tilføj `transition` til din eksisterende `.figur`-regel i CodePen 3:

```css
.figur {
  transform-box: view-box;
  translate: 0% 0%;
  transition: translate 0.5s;
}

@media (prefers-reduced-motion: reduce) {
  .figur {
    transition: none;
  }
}
```

`transition` laver overgangen mellem den gamle og den nye værdi. `0.5s` betyder et halvt sekund. JavaScript-funktionerne er de samme.

**Prøv:** Skift mellem Indgang, Scene og Café. Ændr tiden til `1s`, og sammenlign. Figuren bevæger sig direkte mellem stederne; den følger ikke automatisk den tegnede sti.

Medieforespørgslen slår overgangen fra for brugere, der har valgt mindre bevægelse på deres enhed.

## Brug din egen figur og dine egne steder

1. **Find figurens `<use>`.** Giv det fx `class="figur"`. Bevar din egen filsti, figurens id og SVG’ens `viewBox`.
2. **Find positionerne i CSS.** Afprøv `translate` med `transform-box: view-box`, ét sted ad gangen. Notér værdierne, og sæt derefter startpositionen tilbage.
3. **Giv hver `summary` et unikt id.** Forbind hvert valg med en listener og en navngiven funktion.
4. **Sæt positionen i funktionen.** Brug de værdier, du fandt til netop dit kort, og afprøv skift frem og tilbage.

<div class="slide-takeaway">

Din figur kan starte et andet sted end vores. **Procentværdierne skal derfor findes til din tegning.** Start med to steder, og udvid, når forbindelsen virker.

</div>

Hver ny værdi sættes fra figurens oprindelige placering. Skal den tilbage ved genindlæsning, bestemmes udgangspunktet af din CSS.

</Slide>

JavaScript vælger figurens `<use>` med `.figur`. Dermed kan du flytte personen uden at flytte hele SVG’en.

I Illustrator samler du de dele, der skal bevæge sig sammen, i et selvstændigt lag. Efter eksport kontrollerer du gruppernes id’er og filens `viewBox` i SVG-koden. Den bevægelige figur må ikke også indgå i baggrundsgruppen, da den så bliver tegnet to gange.

På din egen side skal filstien og `viewBox` passe til din fil. Brug Live Server.

**Hvorfor ikke åbne denne variant direkte i CodePen?** Eksterne `<use>`-referencer kræver _samme origin_: samme protokol, domæne og port som HTML-siden. CodePens resultat og SVG-filen på GitHub eller undervisningssitet har forskellige origins. En fuld URL eller CORS-tilladelse på SVG-filen løser ikke i sig selv begrænsningen for `<use>`. Med Live Server hentes HTML og SVG fra samme origin. Se [MDN om eksterne SVG-referencer](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/Linking).

## 1: Giv kortet besked om det valgte sted

I <a href="https://github.com/PeterUlf/E2026-T4-SVG-EKSEMPEL2" target="_blank" rel="noopener noreferrer">Eksempel 2 på GitHub</a> skal figuren følges **det åbne afsnit**, altså den summary der er åben. Vi tager først Scene som eksempel: Hvordan får kortet besked om, at stedet er `scene`?

<div class="slide-split">
<div>

### 1. Gem navnet i HTML

```html mark='data-position="scene"'
<details
  id="details-scene"
  class="accordion-item"
  name="steder"
  data-position="scene"
>
  <summary>Scene</summary>
  <p>Her kan du høre musikken.</p>
</details>
```

`data-position` er en attribut, vi selv har tilføjet. Den gemmer stedets navn: teksten `"scene"`.

</div>
<div>

### 2. Kopiér navnet til kortet

```javascript
const scene = document.querySelector("#details-scene");
const kort = document.querySelector(".svg-kort");

kort.dataset.position = scene.dataset.position;
```

De to `const`-linjer giver os korte navne til afsnittet og SVG-kortet. `dataset.position` er JavaScripts måde at læse og skrive `data-position` på.

Læs den sidste linje sådan: **Hent stedets navn fra `scene`, og gem det på `kort`.**

</div>
</div>

```html mark='data-position="scene"'
<svg
  class="svg-kort"

```

## 2: CSS flytter figuren til det valgte sted

Kortet har nu `data-position="scene"`. **CSS skal oversætte `scene` til den kendte forskydning `40% 0%`.**

<div class="slide-split">
<div>

### 1. Vælg de to tal

```css
.svg-kort {
  --x: 0%;
  --y: 0%;
}
.svg-kort[data-position="scene"] {
  --x: 40%;
  --y: 0%;
}
```

`--x` og `--y` er **CSS-variabler**: navne til de to tal. `--x` er den vandrette forskydning, og `--y` er den lodrette.

Den nederste regel gælder kun, når kortet har `data-position="scene"`.

</div>
<div>

### 2. Brug tallene på figuren

```css
.figur {
  transform-box: view-box;
  translate: var(--x) var(--y);
  transition: translate 0.5s;
}
```

Figurens `<use>` ligger inde i SVG-kortet og **arver de to værdier**. `var(--x)` og `var(--y)` henter dem.

Ved Scene svarer linjen derfor til **`translate: 40% 0%;`** — figuren flyttes mod højre, ligesom i grundforløbet.

</div>
</div>

<div class="slide-takeaway">

**Kortet gemmer stednavnet og de to tal. Figuren bruger tallene til at flytte sig.** Kun `.figur` får `translate`, så baggrunden bliver stående.

</div>

<details>
<summary>Hvad med Café, Indgang og intet valg?</summary>

Tilføj denne regel efter reglerne for kortet:

```css
.svg-kort[data-position="cafe"] {
  --x: 40%;
  --y: 40%;
}
```

| Værdi på kortet                       | Forskydning | Resultat                  |
| ------------------------------------- | ----------- | ------------------------- |
| `scene`                               | `40% 0%`    | Figuren står ved Scene.   |
| `cafe`                                | `40% 40%`   | Figuren står ved Café.    |
| `indgang` eller ingen `data-position` | `0% 0%`     | Figuren står ved Indgang. |

Indgang bruger grundværdierne fra den første `.svg-kort`-regel. Alle forskydninger regnes fra figurens oprindelige placering ved Indgang.

Genopfrisk [CSS-variabler og var()](/css/custom-properties/).

</details>

## 3: Opdatér kortet, når brugeren skifter sted

<div class="slide-split">
<div>

På slide 14 valgte vi Scene direkte. Nu skal en funktion finde **det afsnit, der er åbent**. Browseren giver et åbent `<details>` attributten `open`.

</div>

<div class="slide-split">
<div>

### 1. Find og kopiér det åbne sted

```javascript
const kort = document.querySelector(".svg-kort");

function opdaterFigur() {
  const aabent = document.querySelector(".accordion-item[open]");
  if (aabent) {
    kort.dataset.position = aabent.dataset.position;
  } else {
    delete kort.dataset.position;
  }
}
```

- `.accordion-item[open]` finder et af vores afsnit, som er åbent.
- `if (aabent)`: Vi fandt et — kopiér dets stednavn til kortet.
- `else`: Alle er lukkede — fjern kortets `data-position`. CSS bruger så `0% 0%`, og figuren går til Indgang.

</div>
<div>

### 2. Kør funktionen ved ændringer (eksempel herunder gælder for "scene")

```javascript
document
  .querySelector("#details-scene")
  .addEventListener("toggle", opdaterFigur);

opdaterFigur();
```

`toggle` er en hændelse, browseren sender, **efter et `details` er åbnet eller lukket**. Listeneren får vores funktion til at køre ved begge dele.

Sæt en tilsvarende listener på `#details-indgang` og `#details-cafe`. Alle tre kalder samme funktion.

Det sidste `opdaterFigur()` kører funktionen én gang ved indlæsning, så kortet også passer til det afsnit, der er åbent fra start.

</div>
</div>

<div class="slide-takeaway">

**Åbn Scene → funktionen finder det åbne afsnit → kortet får `scene` → CSS flytter figuren til scenen.**

</div>

<details>
<summary>Samlet JavaScript til alle tre steder</summary>

Denne kode erstatter JavaScript-udsnittet fra slide 14. Brug HTML’en med alle tre afsnit fra slide 14 og CSS’en fra slide 15, inklusive Café-reglen.

```javascript
const kort = document.querySelector(".svg-kort");

function opdaterFigur() {
  const aabent = document.querySelector(".accordion-item[open]");
  if (aabent) {
    kort.dataset.position = aabent.dataset.position;
  } else {
    delete kort.dataset.position;
  }
}

document
  .querySelector("#details-scene")
  .addEventListener("toggle", opdaterFigur);
document
  .querySelector("#details-indgang")
  .addEventListener("toggle", opdaterFigur);
document
  .querySelector("#details-cafe")
  .addEventListener("toggle", opdaterFigur);

opdaterFigur();
```

**Tjek:** Åbn Scene → åbn Café → luk Café. Figuren skal stå ved Scene, derefter Café og til sidst Indgang.

Når et nyt afsnit åbnes, lukker det tidligere automatisk på grund af `name="steder"`. Funktionen finder hver gang det afsnit, der er åbent nu. `delete` fjerner kun kortets `data-position`; selve SVG-kortet bliver på siden.

</details>

## Samme valg kan ændre størrelse og et ekstra punkt

SVG-filen indeholder også `punkt`. De tre `<use>`-elementer står i denne rækkefølge, så personen tegnes øverst:

```html
<use class="baggrund" href="./interaktiv-svg-kort.svg#baggrund"></use>
<use class="punkt" href="./interaktiv-svg-kort.svg#punkt"></use>
<use class="figur" href="./interaktiv-svg-kort.svg#person"></use>
```

<div class="slide-split">
<div>

```css
.figur {
  scale: 1;
  transform-origin: 10% 40%;
}
.svg-kort[data-position="cafe"] .figur {
  scale: 1.2;
}
```

`1.2` gør personen 20 % større. `transform-origin` er centrum for skaleringen. Her er det fødderne ved `(60, 120)` i vores `viewBox`. Behold figurens `transform-box: view-box`.

</div>
<div>

```css
.punkt {
  opacity: 0;
  scale: 1;
  transform-box: fill-box;
  transform-origin: center;
}
.svg-kort[data-position="cafe"] .punkt {
  opacity: 1;
  scale: 1.2;
}
```

`opacity: 0` skjuler punktet, og `1` viser det. `fill-box` lader punktet skalere om midten af sin egen form. Punktet flyttes ikke med procent.

</div>
</div>

**Til din egen figur:** Vælg et passende centrum for skaleringen, og kontrollér placeringen igen, når størrelsen ændres.

## Find det led, der mangler

| Det, du ser                                 | Kontrollér dette                                                                                                               |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Teksten åbner, men funktionen reagerer ikke | Matcher `summary`-id, selector og funktionsnavn? Er scriptet indlæst? Se også Console.                                         |
| Figuren i fil-eksemplet vises ikke          | Kontrollér filsti, `#person`, Live Server og at filen ligger på samme website.                                                 |
| Figuren følger ikke lukning i udvidelsen    | Lyt efter `toggle` på `details`, og kontrollér `delete` samt CSS-grundværdierne.                                               |
| Hele kortet flytter sig                     | Vælger `.figur` dit `<use>` og ikke hele `<svg>`?                                                                              |
| Figuren flytter forkert                     | Er rækkefølgen vandret/lodret? Har `.figur` `transform-box: view-box`?                                                         |
| Rettelser i CSS virker ikke efter et klik   | `.style.translate` har sat en værdi direkte på elementet, som overstyrer CSS-reglen. Genindlæs eller ret værdien i funktionen. |

**Grundforløbet:** Et klik på `summary` ændrer `translate` direkte. **Udvidelsen:** `toggle` på `details` opdaterer SVG-lagets `data-position`, og CSS bestemmer position, størrelse og synlighed.
