## Åbn det lille eksempel i CodePen

Alle tre tekster starter samme sted. De blå baggrunde går helt til kanten; den lyserøde bliver i midten.

<CodePenExample
  title="Forsiden – main og tre sektioner"
  height={240}
  label="Åbn eksemplet i CodePen"
  html={`
    <main>
      <section class="full">
        <div>Oplev vores event</div>
      </section>

      <section class="only_main">
        Program
      </section>

      <section class="full">
        <div>Billetter</div>
      </section>
    </main>

`}
  css={`
/_ Kun for at gøre eksemplet let at se _/
body {
margin: 0;
font: 18px / 1.5 system-ui;
color: #172b3a;
}

    /* Main har tre kolonner: luft, indhold, luft */
    main {
      display: grid;
      grid-template-columns: 1fr 50% 1fr;
    }

    /* Sektionerne starter i midterkolonnen */
    main > * {
      grid-column: 2;
      padding-block: 1rem;
    }

    section.only_main {
      background: #ffd6cc;
    }

    /* En bred sektion får også sit eget grid */
    section.full {
      background: #cce5ff;
      grid-column: 1 / -1;
      display: grid;
      grid-template-columns: inherit;
    }

    section.full > div {
      grid-column: 2;
    }

`}
/>

HTML-panelet indeholder kun `main` og de tre sektioner. CSS-panelet indeholder hele eksemplet. JavaScript-panelet er tomt.

## `main` placerer sektionerne

```css
main {
  display: grid;
  grid-template-columns: 1fr 50% 1fr;
}

main > * {
  grid-column: 2;
  padding-block: 1rem;
}
```

`1fr` på hver side deler den resterende plads ligeligt. Midterkolonnen får halvdelen af bredden.

`main > *` vælger **alle direkte børn af `main`** — her de tre sektioner. `grid-column: 2` placerer dem i midterkolonnen. `padding-block` giver luft foroven og forneden.

**`only_main` ændrer kun baggrundsfarven. Placeringen kommer fra `main > *`.**

## `full` fylder bredden — dens `div` står i midten

```css
section.full {
  background: #cce5ff;
  grid-column: 1 / -1;
  display: grid;
  grid-template-columns: inherit;
}

section.full > div {
  grid-column: 2;
}
```

    <div style="grid-column: 2; background: white; outline: 2px dashed #305b87; padding-block: .75rem; margin: 0; text-align: center;">
      <strong>div · kolonne 2</strong>
      <br />
      Billetter
    </div>
  </div>
</div>

- `grid-column: 1 / -1` placerer **sektionen** fra første til sidste gridlinje i `main`.
- `display: grid` og `inherit` giver sektionen **sit eget grid med samme kolonnedefinition**. Her flugter kolonnerne, fordi sektionen har samme bredde som `main`.
- `section.full > div` placerer **den indre `div`** i sektionens kolonne 2.

**To placeringer: Sektionen i `main`. Teksten i sektionens `div`.**

## `body` laver sidens overordnede grid

Disse regler står allerede i skabelonens **`style.css`**:

<div class="columns-2">
<div>

```css
body {
  margin: 0;
  min-height: 100svh;
  display: grid;
  grid-template-rows: auto 1fr auto;
  grid-template-columns:
    minmax(1rlh, 1fr)
    minmax(0, 75rem)
    minmax(1rlh, 1fr);
}
```

</div>
<div>

**Sidens kant og højde**

- `margin: 0` fjerner browserens standardafstand langs sidens kant.
- `min-height: 100svh` gør siden mindst lige så høj som browserens lille visningsområde — på mobil med browserens værktøjslinjer fremme. Siden kan blive højere, hvis indholdet kræver det.

**Tre rækker: `auto 1fr auto`**

Header og footer får plads efter deres indhold. Den midterste række med `main` tager den resterende højde. Derfor kan footeren stå nederst, selv på en side med lidt indhold.

</div>
</div>

**Tre kolonner: luft · indhold · luft**

`minmax(minimum, maksimum)` angiver, hvor lille og stor en kolonne må være:

- **Midten:** `minmax(0, 75rem)` kan krympe og er højst `75rem`. `rem` følger skriftstørrelsen på `html`.
- **Siderne:** `minmax(1rlh, 1fr)` giver mindst én linjehøjdes luft fra `html` (`1rlh`). De to `1fr` deler den resterende bredde ligeligt, så indholdet står centreret.

</Slide>

## `main` genbruger kolonnerne fra `body`

Disse regler står også allerede i **`style.css`**:

```css
main {
  display: grid;
  grid-template-columns: inherit;
  grid-column: 1 / -1;
  align-content: start;
}

main > * {
  grid-column: 2;
  padding-block: var(--space-3);
}
```

- `grid-column: 1 / -1` lader **hele `main`** spænde over alle tre kolonner i `body`.
- `display: grid` og `grid-template-columns: inherit` giver `main` sit eget grid med kolonnedefinitionen fra `body`.
- `align-content: start` samler sektionernes rækker øverst, selv når `main` har ekstra højde.
- `main > *` placerer **de direkte børn af `main`** i kolonne 2 og giver dem luft foroven og forneden. `--space-3` er her `3rem`.

**Behold grundlayoutet.** CodePens `50%` gjorde kun eksemplet tydeligt. I skabelonen kommer indholdsbredden fra `body`.

Tag princippet med over: Tilføj sektionerne i `main` og CSS-reglerne til `only_main`, `full` og dens indre `div`.

## Faldgruber, når du bygger videre

- **`width: 100%` er ikke nok.** En sektion i kolonne 2 fylder så kun den kolonne. Brug `grid-column: 1 / -1` til at spænde over alle tre.
- **Den brede sektion skal ligge direkte i `main`.** Et ekstra omsluttende element bliver selv placeret i kolonne 2 af `main > *`.
- **Husk den indre `div`.** Reglen `section.full > div` rammer hverken løs tekst eller en `h2` direkte i sektionen. Saml indholdet i én `div`.
- **Der er allerede luft.** `main > *` giver sektionerne `padding-block: var(--space-3)` — her `3rem` foroven og forneden. Det gælder også `full`.
- **Placeringen overskrives, resten bliver.** `section.full` er mere specifik end `main > *` på grund af klassen og vinder for `grid-column`. Det fjerner ikke den eksisterende padding.

**I skabelonen er grundlayoutet klart. Din opgave er at vælge, hvilke sektioner der bliver i midten, og hvilke der skal spænde over alle kolonner.**
