## TL;DR: View Transitions

<p class="pl-lead">
  Lad et lille projektkort blive til en stor projektvisning, når brugeren
  klikker på et link.
</p>

<div class="pl-split">
<div>

**To HTML-sider · ét fælles stylesheet · ingen JavaScript.**

1. **Aktivér på begge sider:** Hele siden toner mellem før og efter.
2. **Giv motivet samme navn:** Browseren forbinder dets placering og størrelse på de to sider.
3. **Vælg varigheden:** Styr motivets overgang med et pseudo-element.
4. **Respektér reduceret bevægelse:** Slå overgangen fra, men bevar linkene.

Begge sider skal ligge på samme **origin**: samme protokol, værtsnavn og port.

</div>
<div>

```css
@view-transition {
  navigation: auto;
}
.motiv {
  view-transition-name: projektmotiv;
}
::view-transition-group(projektmotiv) {
  animation-duration: 400ms;
}
@media (prefers-reduced-motion: reduce) {
  @view-transition {
    navigation: none;
  }
}
```

</div>
</div>

<span slot="takeaway">CSS-layoutet bestemmer før og efter. View Transitions animerer forbindelsen. Uden støtte virker linket stadig.</span>
</Slide>

## Browseren forbinder før og efter

1. Browseren fastholder et billede af den gamle visning — et **snapshot**.
2. Den nye side bliver indlæst.
3. Browseren animerer overgangen mellem den gamle og den nye visning.

Som udgangspunkt toner den gamle visning ud, mens den nye toner ind. Det kaldes en **crossfade**.

En almindelig CSS-`transition` forbinder ændrede egenskaber på et element. View Transitions kan også forbinde visninger fra to forskellige HTML-dokumenter.

<span slot="takeaway">Du bygger begge sider som normalt. Browseren håndterer den visuelle overgang.</span>
</Slide>

## Mellem sider eller på samme side?

| Situation                                       | Hvordan starter overgangen?                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| **Mellem HTML-dokumenter** — cross-document     | Et link og CSS-reglen `@view-transition`.                                |
| **En ændring i samme dokument** — same-document | JavaScript kan bruge `document.startViewTransition()` omkring ændringen. |

**Her arbejder vi med den første løsning.** Vi bruger et projektkort og en separat projektside.

Browserstøtten er forskellig for de to løsninger. Støtte til JavaScript-metoden betyder ikke nødvendigvis støtte til overgange mellem dokumenter.

<span slot="takeaway">View Transitions er ikke det samme som scrollanimationer med <code>view()</code>.</span>
</Slide>

## Start med et færdigt layout

**Tænkt case:** Portfolioen viser plakaten **FORM** som et lille kort. Klik åbner en projektside med en større plakat længere mod højre.

Opret `index.html`, `projekt.html` og `style.css` i samme mappe. **Kopiér alle tre blokke nedenfor nu.** HTML og grund-CSS er færdige; de næste trin tilføjer kun overgangene.

<details class="pl-reveal">
<summary>1. index.html – kopiér hele filen</summary>

```html
<!doctype html>
<html lang="da">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Mine projekter</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <main>
      <h1>Mine projekter</h1>
      <p>Et tænkt plakatprojekt til min portfolio.</p>
      <a class="projektkort" href="projekt.html">
        <div class="motiv motiv-lille" aria-hidden="true">FORM</div>
        <h2 class="projekttitel">FORM – plakat</h2>
        <p>Se projektet →</p>
      </a>
    </main>
  </body>
</html>
```

</details>
<details class="pl-reveal">
<summary>2. projekt.html – kopiér hele filen</summary>

```html
<!doctype html>
<html lang="da">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>FORM – plakat</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <main>
      <a href="index.html">← Tilbage til projekter</a>
      <h1 class="projekttitel">FORM – plakat</h1>
      <div class="motiv motiv-stor" aria-hidden="true">FORM</div>
      <p>Et studie i cirkler, farver og typografi.</p>
    </main>
  </body>
</html>
```

</details>
<details class="pl-reveal">
<summary>3. style.css – kopiér al grund-CSS</summary>

```css
* {
  box-sizing: border-box;
}
body {
  margin: 0;
  padding: 1.5rem;
  font:
    1rem/1.5 system-ui,
    sans-serif;
  color: #18352e;
  background: #f7f5ef;
}
main {
  max-width: 52rem;
  margin: auto;
}
a {
  color: inherit;
}
a:focus-visible {
  outline: 3px solid #185a46;
  outline-offset: 6px;
}
.projektkort {
  display: block;
  width: fit-content;
  max-width: 100%;
}
.projekttitel {
  width: fit-content;
}
.motiv {
  display: grid;
  place-items: center;
  max-width: 100%;
  aspect-ratio: 4 / 3;
  border-radius: 1rem;
  background:
    radial-gradient(circle at 70% 30%, #f4cd64 0 22%, transparent 23%), #b9432d;
  color: white;
  font-size: 2.5rem;
  font-weight: 900;
  letter-spacing: 0.08em;
}
.motiv-lille {
  width: 12rem;
}
.motiv-stor {
  width: 32rem;
  margin-left: auto;
  font-size: 5rem;
}
```

Plakaten er lavet med tekst og en CSS-gradient, så du ikke mangler en billedfil. `aspect-ratio: 4 / 3` bevarer proportionerne. `margin-left: auto` placerer den store plakat mod højre, når der er plads.

</details>

**Afprøv:** Åbn `index.html` med Live Server. Klik på kortet og derefter tilbage-linket i samme fane.

**Du ser:** Et lille og et stort plakatlayout. Skiftet er direkte, uden animation.

**Hvorfor?** CSS beskriver to færdige layouts. Browseren har endnu ikke fået besked om at animere mellem dem.

<span slot="takeaway">Begge sider skal fungere nu. Brug samme Live Server-adresse, fx http://localhost:5500, frem for file://.</span>

## Få hele siden til at tone over

**Tilføj nederst i `style.css`. Behold al grund-CSS.**

```css
@view-transition {
  navigation: auto;
}
```

**Afprøv:** Gem, og klik på kortet og tilbage-linket igen. Brug linkene; genindlæsning eller indtastning i adresselinjen er ikke samme test.

**Du ser:** Den gamle side toner ud, mens den nye toner ind. Plakaten bevæger sig endnu ikke selvstændigt fra lille til stor.

**Hvorfor?** `navigation: auto` tilmelder begge dokumenter, fordi de indlæser samme stylesheet. Browserens standardovergang er en **crossfade** mellem snapshots af hele siderne.

<p class="pl-meta">
  Hvis siden stadig skifter direkte: kontrollér, at CSS er gemt og indlæst på
  begge sider, at adresserne har samme origin, og at browseren understøtter
  cross-document View Transitions. Reduceret bevægelse slås først fra i trin 5 i
  vores kode.
</p>

<span slot="takeaway">Aktivering giver en overgang for hele siden. Den forbinder endnu ikke plakaten som et selvstændigt element.</span>
</Slide>

## Lad plakaten flytte sig og vokse

**Tilføj nederst i `style.css`. Behold trin 1 og 2.**

```css
.motiv {
  view-transition-name: projektmotiv;
}
```

**Afprøv:** Klik frem og tilbage. Følg selve plakaten.

**Du ser:** Den lille plakat bliver nu forbundet med den store. Den skifter størrelse og placering, mens resten af siden fortsat toner over.

**Hvorfor?** Begge plakater får navnet `projektmotiv`. Browseren tager særskilte snapshots af dem og animerer forskellen mellem deres to layouts.

- `.motiv` er CSS-klassen, der **vælger elementet**.
- `projektmotiv` er navnet, der **matcher før og efter**.
- Navnet skal være unikt på hver side. To synlige elementer med samme navn på én side får overgangen til at blive sprunget over.

<span slot="takeaway">Den fælles klasse var ikke nok i trin 2. Det er view-transition-name, der forbinder de to elementer.</span>
</Slide>

## Sæt tempoet ned, og se forskellen

**Tilføj nederst i `style.css`. Behold trin 1–3.**

```css
::view-transition-group(projektmotiv) {
  animation-duration: 1200ms;
}
```

**Afprøv:** Klik frem og tilbage. Følg plakaten, og sammenlign med teksten omkring den.

**Du ser:** Plakatens overgang varer nu **1,2 sekunder**. Resten af siden har stadig browserens korte standardovergang.

**Hvorfor?** `::view-transition-group(projektmotiv)` vælger den gruppe, browseren opretter til plakatens overgang. Det er et **pseudo-element**, som vi kan style uden ekstra HTML.

| Selector                                | Hvad vælger den?                                  |
| --------------------------------------- | ------------------------------------------------- |
| `::view-transition-group(projektmotiv)` | Gruppen, der styrer bl.a. placering og størrelse. |
| `::view-transition-old(projektmotiv)`   | Det gamle snapshot.                               |
| `::view-transition-new(projektmotiv)`   | Det nye snapshot.                                 |

<span slot="takeaway">1200ms er bevidst langsomt, så du kan se teknikken. Vi sætter tempoet op igen til sidst.</span>
</Slide>

## Lad brugerens indstilling bestemme

**Tilføj nederst i `style.css`, efter de andre regler.**

```css
@media (prefers-reduced-motion: reduce) {
  @view-transition {
    navigation: none;
  }
}
```

**Afprøv:** Slå reduceret bevægelse til i systemets tilgængelighedsindstillinger eller browserens udviklerværktøjer. Klik på linkene igen. Slå indstillingen fra, og gentag.

**Du ser:** Med reduceret bevægelse skifter siden direkte. Uden indstillingen vender den langsomme overgang tilbage.

**Hvorfor?** `prefers-reduced-motion: reduce` aflæser brugerens ønske om mindre bevægelse. Den senere regel med `navigation: none` fravælger dokumenternes overgang, når ønsket er aktivt.

<span slot="takeaway">Både plakatens bevægelse og sidens crossfade slås fra. Indhold, links og layout er stadig brugbare.</span>
</Slide>

## Gør overgangen klar til brug

**Find reglen fra trin 4, og erstat `1200ms` med `400ms`.** Behold resten af filen, også reglen for reduceret bevægelse.

```css
::view-transition-group(projektmotiv) {
  animation-duration: 400ms;
}
```

**Du ser:** Samme bevægelse på **0,4 sekunder**. Den er hurtigere, men brugeren kan stadig følge plakaten. Reduceret bevægelse virker fortsat.

**Hvorfor?** Vi ændrer kun varigheden. Start og slut bestemmes stadig af de to siders layout.

## Lad titlen følge med selvstændigt

Brug de tre filer fra eksemplet. Motivets overgang virker allerede.

**Jeres mål:** Titlen “FORM – plakat” skal også forbindes mellem siderne, men have **sin egen overgang på 250ms**. Motivets overgang skal fortsat være 400ms.

- Vælg titlen via den eksisterende klasse `projekttitel`.
- Giv titlen en selvstændig identitet i overgangen.
- Bevar reduceret bevægelse og almindelige links.

**Resultat:** To elementer, der hver kan følges fra oversigt til detalje. Vis begge retninger, og forklar, hvorfor de skal have forskellige navne.

<details class="pl-reveal">
<summary>Hint</summary>

Hvilken regel forbinder motivet på de to sider? Hvad skal ændres, så titlen får sin egen gruppe, og hvilken selector styrer gruppens varighed?

</details>
<details class="pl-reveal">
<summary>Løsningsforslag efter jeres forsøg</summary>

Tilføj i `style.css`:

```css
.projekttitel {
  view-transition-name: projekttitel;
}
::view-transition-group(projekttitel) {
  animation-duration: 250ms;
}
```

Der er kun én `projekttitel` på hver side. Den kan derfor matches på tværs, selv om HTML-tagget er `h2` på oversigten og `h1` på detaljesiden. Motivet beholder sit navn `projektmotiv`.

</details>

## Kan brugeren følge begge elementer?

| Niveau              | Tegn på forståelse                                                               |
| ------------------- | -------------------------------------------------------------------------------- |
| På vej              | Linkene virker, men kun motivet har sin egen overgang, eller navne er dublerede. |
| Det fungerer        | Titel og motiv har forskellige navne og de aftalte varigheder.                   |
| Du kan forklare det | I forklarer matchningen, viser begge retninger og afprøver reduceret bevægelse.  |

Byt betjening. Brug både mus og tastatur. Afprøv også et smalt vindue.

**Ret mindst én ting** i jeres løsning eller forklaring, og gentag afprøvningen. Hvis animationen mangler, kontrollér browserstøtte, samme origin, CSS på begge sider og unikke navne.

## Tre regler at huske

1. **`@view-transition`** aktiverer overgangen på begge sider.
2. **`view-transition-name`** forbinder et element før og efter.
3. **`::view-transition-group()`** lader dig tilpasse gruppens animation.

**Forklar selv:** Hvad kan gå galt, hvis to projektkort på samme side begge får `view-transition-name: projektmotiv`?

<details class="pl-reveal">
<summary>Se forklaringen efter dit eget bud</summary>

Navnet er ikke længere unikt i dokumentet. Browseren kan springe overgangen over. Brug forskellige navne til forskellige elementer, og match det relevante navn på destinationssiden.

</details>
