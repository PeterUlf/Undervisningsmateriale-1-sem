## Hvad er en CSS-animation?

En CSS-animation ændrer et elements udseende over tid uden JavaScript — fx når en besked toner frem.

1. **`@keyframes`** beskriver animationens trin. `from` er starten (0 %), og `to` er slutningen (100 %).
2. **`animation`** kobler trinene til et element og bestemmer bl.a. varigheden.

```css
@keyframes fade-in {
  from {
    opacity: 0;
  } /* Gennemsigtig */
  to {
    opacity: 1;
  } /* Synlig */
}

.besked {
  animation: fade-in 1s;
}
```

Et element med `class="besked"` toner frem én gang over ét sekund, når animationen anvendes. Browseren beregner selv værdierne mellem start og slut.

<span slot="takeaway">Navnet <code>fade-in</code> skal være det samme begge steder. <code>@keyframes</code> alene starter ikke en animation.</span>

[Læs mere: MDN om CSS-animationer](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Animations/Using)

## Keyframes - From/To

Den simpleste måde at definere en animation på:

```css
@keyframes fade-in {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}
```

</Slide>

<Slide variant="lesson" label="Tema 4 · CSS / Animationer">
## Keyframes - Procent

For mere kontrol kan du bruge procent til at definere flere trin:

```css
@keyframes bounce {
  0% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-30px);
  }
  100% {
    transform: translateY(0);
  }
}
```

## Animation Properties

```css
.element {
  animation-name: bounce; /* Hvilket keyframe */
  animation-duration: 2s; /* Hvor lang tid */
  animation-timing-function: ease; /* Hastighed-kurve */
  animation-delay: 0.5s; /* Vent før start */
  animation-iteration-count: 3; /* Antal gentagelser */
  animation-direction: alternate; /* Retning */
  animation-fill-mode: forwards; /* Hvad sker før/efter */
}
```

## Timing Functions

Styrer hvordan hastigheden ændrer sig gennem animationen:

```css
/* Foruddefinerede */
animation-timing-function: linear; /* Konstant hastighed */
animation-timing-function: ease; /* Langsom start/slut */
animation-timing-function: ease-in; /* Langsom start */
animation-timing-function: ease-out; /* Langsom slut */
animation-timing-function: ease-in-out; /* Langsom begge ender */

/* Custom med cubic-bezier */
animation-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

## Direction


## Fill Mode

Bestemmer hvordan elementet ser ud før og efter animationen:

```css
animation-fill-mode: none; /* Normal før/efter */
animation-fill-mode: forwards; /* Behold slut-tilstand */
animation-fill-mode: backwards; /* Start med første keyframe */
animation-fill-mode: both; /* Både forwards og backwards */
```

## Praktiske Eksempler

### Fade In

```css
@keyframes fade-in {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

.fade-in {
  animation: fade-in 1s ease-in;
}
```

```css
@keyframes slide-in-left {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

.slide-in-left {
  animation: slide-in-left 0.6s ease-out;
}
```

## Pause og Play

Du kan styre om en animation kører eller er sat på pause:

```css
.element {
  animation: spin 2s linear infinite;
  animation-play-state: running; /* Standard */
}

.element:hover {
  animation-play-state: paused; /* Pause ved hover */
}
```

## Tips og Tricks

### 1. Performance

Animer kun `transform` og `opacity` for bedst performance:

```css
/* ✅ Godt - hardware accelereret */
@keyframes good {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(100px);
  }
}

/* ❌ Dårligt - kan være hakket */
@keyframes bad {
  from {
    left: 0;
  }
  to {
    left: 100px;
  }
}
```

</Slide>
<div class="page-break"></div>
<Slide variant="lesson" label="Tema 4 · CSS / Animationer">
### 2. will-change

Giv browseren et hint om hvad der skal animeres, så den kan optimere i forvejen:

```css
.element {
  will-change: transform, opacity;
  animation: slide-in 1s;
}
```

**Hvorfor bruge will-change?**

Når browseren ved hvad der skal animeres, kan den forberede sig ved at:

- Oprette et separat lag til animationen
- Allokere hukommelse på forhånd
- Bruge GPU acceleration

**Resultat:** Mere flydende animationer, især på mobile enheder.

**Vigtigt:** Brug det kun på elementer der faktisk skal animeres. Hvis du bruger det på ALT, bliver det langsommere i stedet for hurtigere.

</Slide>
<div class="page-break"></div>
<Slide variant="lesson" label="Tema 4 · CSS / Animationer">

### 3. Reduced Motion

Respekter brugere der har slået animationer fra i deres system-indstillinger:

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01s !important;
    animation-iteration-count: 1 !important;
  }
}
```

**Hvor skal denne kode placeres?**

Denne CSS skal placeres **i bunden af din CSS-fil**, efter alle dine animationer. Det sikrer at den overskriver alle animationer når brugeren har slået dem fra.

**Eksempel:**

```css
/* Dine animationer */
@keyframes slide-in {
  from {
    transform: translateX(-100px);
  }
  to {
    transform: translateX(0);
  }
}

.box {
  animation: slide-in 1s;
}

/* Reduced motion - ALTID I BUNDEN */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01s !important;
    animation-iteration-count: 1 !important;
  }
}
```

Dette er vigtigt for tilgængelighed - nogle mennesker bliver faktisk syge af bevægelse på skærmen.

</Slide>

## Animation vs Transition

**Animation**: Kører automatisk, kan have flere steps, kan loope

```css
.box {
  animation: spin 2s infinite;
}
```

**Transition**: Kræver en state-ændring (hover, class, etc.), kun start og slut

```css
.box {
  transition: transform 0.3s;
}
.box:hover {
  transform: scale(1.2);
}
```

## Browser Support

CSS animationer er understøttet i alle moderne browsere. For meget gamle browsere kan du bruge prefixes:

```css
@-webkit-keyframes slide-in {
  from {
    transform: translateX(-100px);
  }
  to {
    transform: translateX(0);
  }
}

@keyframes slide-in {
  from {
    transform: translateX(-100px);
  }
  to {
    transform: translateX(0);
  }
}
```

Men det er sjældent nødvendigt i dag.
