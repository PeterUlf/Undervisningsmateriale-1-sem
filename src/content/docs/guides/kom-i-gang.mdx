## Forudsætninger 🛠️

For at komme i gang har du brug for:

- **En teksteditor** (f.eks. [VS Code](https://code.visualstudio.com/download))
- **En webbrowser** (Chrome, Firefox, Safari)
- **Git installeret** (se [Git & GitHub guiden](/git/))
- **Nysgerrighed** (Vigtigst!)

## Din første HTML-side 📄

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Hej Verden!</h1>
  </body>
</html>
```

1. Opret `index.html`
2. Indsæt koden
3. Åbn i browseren

## Mini-projekter (samler emnerne)

1. **Profilside**  
Byg en personlig side med semantisk HTML og grundlæggende CSS.  
Start her: [HTML Grundlæggende](/html/grundlaeggende), [Semantisk HTML](/html/semantisk), [Intro til CSS](/css/intro)

2. **Produktside med kort**  
Lav et layout med flere cards i Grid og tilføj en lille JS-interaktion (fx like-knap).  
Start her: [Grid](/css/grid), [Intro til JavaScript](/javascript/)

3. **Mini-site i Astro**  
Byg en lille side med layout + komponenter og deploy den.  
Start her: [Astro – Installation](/astro/installation), [Astro – Komponenter](/astro/komponenter), [Astro – Deploy](/astro/deploy-netlify)
