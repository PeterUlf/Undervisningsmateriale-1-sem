# Genvejstaster – Øvelser

Praktiske øvelser til at træne de vigtigste genvejstaster. Nogle øvelser har tekstbokse hvor du kan øve dig direkte på siden, andre kræver VS Code.

⌘ => Ctrl

## 🎯 Øvelse: Grundlæggende redigering

**Prøv følgende i tekstboksen nedenfor:**

1. **Skriv denne tekst:** `Hej med dig, jeg hedder [dit navn]`
2. **Marker dit navn** (dobbeltklik eller træk)
3. **Kopier** navnet med `⌘/Ctrl + C`
4. **Flyt cursoren** til slutningen af linjen med `⌘ + →` (Mac) eller `End` (PC)
5. **Sæt ind** med `⌘/Ctrl + V` tre gange for at gentage dit navn
6. **Fortryd** den sidste indsættelse med `⌘/Ctrl + Z`
7. **Marker hele linjen** med `⌘/Ctrl + A`
8. **Klip** teksten med `⌘/Ctrl + X`
9. **Sæt ind igen** med `⌘/Ctrl + V`

## 🎯 Øvelse: Søgning og markering

**Prøv i tekstboksen nedenfor:**

1. **Find et ord** med `⌘/Ctrl + F` (åbner browser søgning)
2. **Skriv flere linjer** tekst med gentagende ord
3. **Marker et ord** (dobbeltklik)
4. **Brug** `Shift + Option/Alt + →` for at udvide markeringen ord for ord
5. **Brug** `Shift + ⌘/Ctrl + →` for at markere resten af linjen
6. **Øv** at markere frem og tilbage med `Shift + piletaster`

## 🎯 Øvelse: Kommentarer

**Åbn VS Code ([vscode.dev](https://vscode.dev)) og opret en ny fil:**

**Forberedelse:**

1. Opret en ny fil: `test.js`
2. Kopier denne tekst over i filen:

```javascript
const name = "Peter";
const age = 35;
const city = "København";
console.log(name);
```

**Nu skal du øve:**

1. **Placer cursoren** på linjen med `const name`
2. **Lav HTML grundstruktur** - skriv `!` og tryk `Tab` for at få en komplet HTML-skabelon
3. **Kommenter linjen** med `⌘/Ctrl + /`
4. **Uncommenter igen** ved at trykke `⌘/Ctrl + /` igen
5. **Markér alle 4 linjer** (placer cursoren på første linje, hold `Shift` nede og tryk pil-ned 3 gange, eller brug `⌘/Ctrl + A` for at markere alt)
6. **Kommenter dem alle** med `⌘/Ctrl + /`
7. **Uncommenter alle** igen
8. **Markér teksten** `"Peter"` (inkl. anførselstegn)
9. **Prøv blok-kommentar** med `⌘ + Option + /` (Mac) eller `Ctrl + Shift + A` (PC)

:::tip[Smart!]
VS Code tilpasser automatisk kommentar-syntaksen til filtypen:

- JavaScript/CSS: `//` eller `/* */`
- HTML: `<!-- -->`
- Python: `#`
  :::

## 🎯 Øvelse: Linje manipulation

**Åbn VS Code ([vscode.dev](https://vscode.dev)) og opret en HTML-fil:**

**Forberedelse:**

1. Opret en ny HTML-fil: `test.html`
2. Lav HTML grundstruktur - skriv `!` og tryk `Tab` for at få en komplet HTML-skabelon
3. Kopier denne liste over i `<body>`-tagget (mellem `<body>` og `</body>`):

```html
<ol>
  <li>Første punkt</li>
  <li>Andet punkt</li>
  <li>Tredje punkt</li>
</ol>
```

**Nu skal du øve:**

1. **Placer cursoren** på linjen med "Andet punkt"
2. **Flyt linjen op** med `Option/Alt + ↑` (nu skal den være over "Første punkt")
3. **Flyt den ned igen** med `Option/Alt + ↓` to gange
4. **Kopier linjen** med `Shift + Option/Alt + ↓` (duplikér 2-3 gange)
5. **Slet en af linjerne** med `⌘/Ctrl + Shift + K`
6. **Indsæt ny linje under** med `⌘/Ctrl + Enter` og skriv noget nyt
7. **Indsæt ny linje over** med `⌘/Ctrl + Shift + Enter`

:::tip[Hurtig workflow]
Disse genvejstaster er nogle af de mest brugte i daglig kodning - de sparer dig for meget copy-paste!
:::

## 🎯 Øvelse: Multi-cursor magi

**Åbn VS Code ([vscode.dev](https://vscode.dev)) og opret en HTML-fil:**

**Forberedelse:**

1. Opret en ny HTML-fil: `test2.html`
2. Lav HTML grundstruktur - skriv `!` og tryk `Tab` for at få en komplet HTML-skabelon
3. Kopier denne HTML-liste over i `<body>`-tagget (mellem `<body>` og `</body>`):

```html
<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
  <li>Item 4</li>
</ol>
```

**Opgave 1: Omdøb "Item" til "Punkt"**

1. **Dobbeltklik** på ordet "Item" på første linje
2. **Tryk** `⌘/Ctrl + D` tre gange for at markere "Item" på alle linjer
3. **Skriv** "Punkt" - det erstattes alle steder!

**Opgave 2: Tilføj klasse på alle `<li>` tags**

1. **Placer cursor** efter `<li` på første linje
2. **Tryk** `⌘/Ctrl + Option/Alt + ↓` tre gange for cursors på alle linjer
3. **Skriv** ` class="list-item"` - det tilføjes alle steder!

**Opgave 3: Alt + klik**

1. **Hold** `Option/Alt` nede
2. **Klik** på 4 forskellige steder i din kode
3. **Skriv** noget - det indsættes alle steder!

:::tip[Pro tip]
Hvis du vil markere alle forekomster af et ord, markér ordet og tryk `⌘/Ctrl + Shift + L` - så får du multi-cursor på alle steder!
:::

:::tip[Mind = Blown 🤯]
Multi-cursor er en superkraft! Det sparer dig for meget tid.
:::

## 🎯 Øvelse: Navigation i VS Code

**Åbn VS Code ([vscode.dev](https://vscode.dev)) med flere filer:**

**Forberedelse:**

1. Opret 2-3 forskellige filer (f.eks. `index.html`, `styles.css`, `script.js`)
2. Skriv lidt indhold i hver fil

**Nu skal du øve:**

1. **Quick Open:** Tryk `⌘/Ctrl + P`
   - Skriv navnet på en af dine filer
   - Tryk Enter for at åbne den
   - Prøv at skrive kun første bogstav fra hvert ord (f.eks. "stcss" for "styles.css")

2. **Command Palette:** Tryk `⌘/Ctrl + Shift + P`
   - Skriv "format" og vælg "Format Document"
   - Prøv at søge efter "theme" og skift farvetema

3. **Gå til linje:** Tryk `⌘/Ctrl + G`
   - Skriv et linjenummer og hop direkte dertil

4. **Split editor:** Tryk `⌘/Ctrl + \`
   - Åbn samme fil side-by-side
   - Skift mellem dem med `⌘/Ctrl + 1` og `⌘/Ctrl + 2`

:::tip[Power User Tip]
`⌘/Ctrl + P` kan mere! Prøv:

- `@symbolname` - søg efter funktioner/klasser i filen
- `:42` - gå til linje 42
- `?` - se alle mulige kommandoer
  :::
